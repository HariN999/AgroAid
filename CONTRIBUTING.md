# 🤝 Contributing to AgroAid

Thank you for considering contributing to **AgroAid**! 🚜  
We welcome all contributions — from bug fixes and improvements to new features or documentation.

---

## 📋 How to Contribute

### 1. Fork the Repository

Click the **Fork** button on the top right of this page to create your own copy.

### 2. Clone Your Fork

```bash
git clone https://github.com/HariN999/AgroAid
cd AgroAid
```

### 3. Create a New Branch

```bash
git checkout -b feature/YourFeatureName
```

### 4. Make Changes

Implement your feature, bug fix, or documentation update. Make sure your code follows good practices and is well-commented.

### 5. Commit Your Changes

```bash
git add .
git commit -m "feat: add YourFeatureName"
```

### 6. Push to Your Fork

```bash
git push origin feature/YourFeatureName
```

### 7. Submit a Pull Request

Go to your fork on GitHub, click "Compare & Pull Request", and describe your changes clearly.

---

## 🧪 Guidelines

- Keep pull requests focused and concise.
- Write clear, descriptive commit messages.
- Format code properly and test before submitting.
- Feel free to ask for help in the [issues](https://github.com/HariN999/AgroAid/issues) tab.
